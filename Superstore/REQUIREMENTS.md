# Superstore Return Rate Analysis  
### By Cassey Cam

## Overview

This project analyzes return rates at a fictional Superstore using Tableau. The goal is to identify the main drivers behind high return rates and recommend strategies to reduce them. The analysis is designed to support data-informed decision-making for executive stakeholders.

---

## Deliverables

- **Interactive Tableau Dashboard**  
  Explore visualizations on return trends by geography, time, category, and customer behavior.  
  [View Dashboard](https://public.tableau.com/shared/WHZRGS8MJ?:display_count=n&:origin=viz_share_link)

- **Presentation Notes and Graph Descriptions**  
  Detailed explanations for each graph and guidance for communicating insights.  
  [View Google Doc](https://docs.google.com/document/d/1J_A0H6PHSFTPBVPgETaHQMb5xLfRqt2XQ1WHFuh1ZwA/edit?usp=sharing)

---

## Business Question

**What is causing the high number of returned orders at the Superstore, and how can the company reduce them?**

---

## Tools Used

- **Tableau Public** – Data visualization and dashboard creation  
- **Google Docs** – Documentation of findings and presentation prep
- **Excel** – To Import Data to Tableau

---

## Features

- Return rate analysis by:
  - Region
  - Product Category and Subcategory
  - Customer behavior
  - Time (monthly trends)
- Interactive filters for:
  - Date
  - State
  - Category
  - Subcategory

---

## How to Use

1. Open the Tableau dashboard via the link above.
2. Use filters to explore different dimensions of return data.
3. Refer to the documentation for interpretation of graphs and key insights.
