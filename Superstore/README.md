## Business Question

**What is causing the high number of returned orders at the Superstore?**  
This project presents a detailed analysis intended for the CEO of Superstore. It investigates the drivers of customer returns and provides actionable insights to help reduce return volume and optimize profitability.

---

## Key Findings

In this analysis, we aim to understand return rates by identifying key insights and potential actions to reduce returns. By examining return rates across different dimensions—geography, time, product categories, and customer behavior—we can develop data-driven strategies to improve business outcomes.

### Return Rate Metrics

- **Primary Metric**: Return rate percentage = (Total Returned Items / Total Items Sold)
- **Supporting Metrics**:  
  - Total number of returns  
  - Total sales revenue  
  - Financial impact of high-value product returns  

### Geographic Insights

- A color-coded map reveals regional return rate patterns.
- States such as **Utah**, **Oregon**, and **California** exhibit the **highest return rates**.
- These patterns may reflect shipping issues, customer expectations, or product suitability in these areas.

### Product Category Trends

- A bar chart highlights return rates across product categories.
- **Technology** has the highest return rate—possibly due to product defects, incomplete accessories, or poor product descriptions.
- **Furniture** shows the **lowest return rate** and the **highest profit**, suggesting it should be a focus for investment.

### Seasonal and Time-Based Trends

- A time-series line chart illustrates how return rates change month by month.
- **April** shows the highest return rate, possibly due to post-holiday returns, warranty expirations, or seasonal customer behavior.

### Customer Behavior Patterns

- A bar chart highlights the **top 15 customers with the highest return rates** (excluding one-time returners).
- This helps identify frequent returners, enabling personalized support strategies to reduce returns without compromising customer loyalty.

### Combined Regional and Seasonal Trends

- A stacked bar chart analyzes return rates by **region and time**.
- The **Western region** consistently shows higher return rates, pointing to potential issues in shipping, product fit, or customer expectations in that area.

### Sales vs. Returns Correlation

- A scatterplot reveals a **positive correlation** between sales volume and return volume.
- Identifying specific high-sales, high-return products can help uncover quality control issues or marketing misalignment.

### Sales and Returns Over Time by Category

- A combined bar and line chart explores sales alongside return rates across time and product categories.
- Return spikes following sales events (e.g., Black Friday) suggest impulsive buying behavior and the need for better pre-purchase guidance or refined return policies.

## Interactive Dashboard Features

The dashboard includes filters to allow users to drill into the data:

1. **Category Filter** – View return trends by product category.  
2. **State Filter** – Analyze return patterns by geographic location.  
3. **Date Filter** – Identify seasonal or event-driven return behavior.  
4. **Subcategory Selection** – Examine specific product types in greater detail.

---

## Conclusion

- The **Western region** should be prioritized for investigation due to its consistently high return rates.
- **Furniture** is a profitable, low-return product category—ideal for future investment.
- **Technology**, with its high return rates, warrants close monitoring and improved quality control, customer education, and clearer marketing.
